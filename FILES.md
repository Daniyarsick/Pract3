# Описание файлов проекта Alien Invasion

## О чем этот проект?

**Alien Invasion** - это классическая 2D аркадная игра в стиле "Space Invaders", где игрок управляет космическим кораблем и защищает Землю от флота атакующих инопланетян. Проект реализован на Python с использованием библиотеки Pygame и демонстрирует принципы объектно-ориентированного программирования в разработке игр.

## Основные игровые файлы

### `alien_invasion.py` - Главный файл игры
**Что это:** Основной класс `AlienInvasion`, который управляет всей игрой
**Что делает:**
- Инициализирует Pygame и создает игровое окно
- Запускает главный игровой цикл
- Обрабатывает события клавиатуры и мыши
- Управляет взаимодействием между всеми игровыми объектами
- Обрабатывает коллизии и игровую логику

### `ship.py` - Космический корабль игрока
**Что это:** Класс `Ship` для корабля игрока
**Что делает:**
- Управляет движением корабля влево/вправо
- Отображает спрайт корабля на экране
- Обрабатывает границы экрана
- Центрирует корабль при начале новой жизни

### `alien.py` - Инопланетные захватчики
**Что это:** Класс `Alien` для вражеских пришельцев
**Что делает:**
- Управляет движением пришельцев по горизонтали
- Проверяет достижение краев экрана
- Работает в составе флота с коллективным поведением

### `bullet.py` - Система пуль
**Что это:** Класс `Bullet` для снарядов корабля
**Что делает:**
- Создает пули в позиции корабля
- Двигает пули вертикально вверх
- Автоматически удаляет пули за пределами экрана

### `settings.py` - Настройки игры
**Что это:** Класс `Settings` с конфигурацией игры
**Что делает:**
- Хранит размеры экрана и игровых объектов
- Определяет скорости движения всех объектов
- Управляет цветами и визуальными параметрами
- Содержит звуковые эффекты
- Обеспечивает прогрессивное увеличение сложности

### `game_stats.py` - Статистика игры
**Что это:** Класс `GameStats` для отслеживания игрового прогресса
**Что делает:**
- Отслеживает текущий счет игрока
- Управляет количеством оставшихся жизней
- Контролирует текущий уровень
- Сохраняет рекорд игры

### `scoreboard.py` - Отображение статистики
**Что это:** Класс `Scoreboard` для визуализации игровой информации
**Что делает:**
- Отображает текущий счет, уровень и рекорд
- Показывает оставшиеся жизни в виде корабликов
- Динамически обновляется при изменениях

### `button.py` - Интерфейсные элементы
**Что это:** Класс `Button` для интерактивных кнопок
**Что делает:**
- Создает кнопку "Play" для начала игры
- Обрабатывает нажатия мыши на кнопку
- Отображает кнопки с текстом и цветом

## Вспомогательные файлы

### `utils.py` - Утилитарные функции
**Что это:** Набор вспомогательных функций
**Что делает:**
- `resource_path()` - получает правильные пути к ресурсам (поддерживает PyInstaller)
- `hide_mouse_cursor()` - скрывает курсор мыши во время игры

### `color.py` - Цветовая схема
**Что это:** Константы цветов для игры
**Что делает:**
- Определяет основные цвета (фон, белый цвет и др.)
- Централизует управление цветовой схемой

### `game_functions.py` - Дополнительные игровые функции
**Что это:** Дополнительные утилиты для игры
**Что делает:**
- Содержит вспомогательные функции для обработки событий
- Дополнительная игровая логика

## Как все это работает вместе?

1. **`alien_invasion.py`** импортирует все необходимые компоненты
2. **`settings.py`** предоставляет конфигурацию для всех объектов
3. **`ship.py`**, **`alien.py`**, **`bullet.py`** создают игровые объекты
4. **`game_stats.py`** и **`scoreboard.py`** отслеживают и отображают прогресс
5. **`button.py`** обеспечивает интерфейс управления
6. **`utils.py`** и **`color.py`** предоставляют общие утилиты
7. Файлы в **`images/`** и **`sounds/`** обеспечивают аудиовизуальный опыт

## Запуск проекта

```bash
# Установка зависимостей
pip install pygame

# Запуск игры
python alien_invasion.py

# Тестирование
python test_game.py
python demo.py
```

Этот проект демонстрирует создание полноценной игры с использованием современных принципов разработки: модульность, объектно-ориентированное программирование, обработка ресурсов и тестирование.
