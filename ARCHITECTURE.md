# Документация проекта Alien Invasion

## Архитектура проекта

Этот проект представляет собой объектно-ориентированную реализацию классической аркадной игры "Alien Invasion" с использованием библиотеки Pygame.

## Основные компоненты

### 1. AlienInvasion (alien_invasion.py)
Главный класс, который управляет всей игрой:
- Инициализирует Pygame и создает игровое окно
- Управляет игровым циклом
- Обрабатывает события пользователя
- Координирует взаимодействие между всеми игровыми объектами
- Загружает и управляет звуковыми эффектами

**Ключевые методы:**
- `run_game()` - основной игровой цикл
- `respond_to_events()` - обработка событий клавиатуры и мыши
- `create_fleet_of_aliens()` - создание флота инопланетян
- `manage_bullet_alien_collision()` - обработка столкновений

### 2. Ship (ship.py)
Класс космического корабля игрока:
- Наследует от pygame.sprite.Sprite
- Управляет движением корабля
- Отображает спрайт корабля на экране
- Обрабатывает позиционирование и границы экрана

**Основные атрибуты:**
- `moving_left/right` - флаги движения
- `x` - точная позиция (float для плавного движения)
- `rect` - прямоугольник для коллизий

### 3. Alien (alien.py)
Класс инопланетянина:
- Наследует от pygame.sprite.Sprite
- Управляет движением пришельцев по горизонтали
- Обрабатывает спуск флота при достижении края экрана
- Проверяет границы экрана

**Особенности:**
- Автоматическое движение по заданному направлению
- Синхронизация с другими пришельцами в флоте

### 4. Bullet (bullet.py)
Класс пули/снаряда:
- Наследует от pygame.sprite.Sprite
- Создается в позиции корабля
- Движется вертикально вверх
- Автоматически удаляется при выходе за пределы экрана

**Характеристики:**
- Высокая скорость движения
- Прямоугольная форма
- Ограничение количества на экране

### 5. Settings (settings.py)
Центральное хранилище всех настроек игры:
- Размеры экрана и игровых объектов
- Скорости движения
- Цвета и визуальные параметры
- Звуковые эффекты
- Динамические настройки, меняющиеся с уровнем

**Динамические настройки:**
- Увеличение скорости с каждым уровнем
- Изменение сложности игры
- Масштабирование очков

### 6. GameStats (game_stats.py)
Управление статистикой игры:
- Отслеживание текущего счета
- Управление количеством жизней
- Контроль уровня игры
- Сохранение рекорда

**Состояния:**
- `game_active` - активность игры
- Статистика, которая сбрасывается каждую игру
- Постоянные данные (рекорд)

### 7. Scoreboard (scoreboard.py)
Отображение игровой статистики:
- Рендеринг текста счета, уровня, рекорда
- Отображение оставшихся жизней в виде корабликов
- Динамическое обновление при изменении статистики

### 8. Button (button.py)
Интерактивные элементы интерфейса:
- Кнопка "Play" для начала игры
- Обработка нажатий мыши
- Визуальное оформление кнопок

### 9. Вспомогательные модули

#### utils.py
- `resource_path()` - получение путей к ресурсам (поддерживает PyInstaller)
- `hide_mouse_cursor()` - скрытие курсора мыши

#### color.py
- Константы цветов для игры
- Централизованное управление цветовой схемой

#### game_functions.py
- Дополнительные игровые функции
- Утилиты для обработки событий

## Игровая логика

### Жизненный цикл игры
1. Инициализация всех компонентов
2. Отображение начального экрана с кнопкой "Play"
3. Главный игровой цикл:
   - Обработка событий
   - Обновление позиций объектов
   - Проверка коллизий
   - Обновление экрана
4. Обработка окончания игры

### Система коллизий
- Пули ↔ Пришельцы: уничтожение и начисление очков
- Корабль ↔ Пришельцы: потеря жизни
- Пришельцы достигают дна: потеря жизни

### Прогрессия уровней
- При уничтожении всех пришельцев - переход на следующий уровень
- Увеличение скорости игры
- Увеличение стоимости пришельцев в очках

## Особенности реализации

### Использование Pygame Sprites
Все игровые объекты наследуют от `pygame.sprite.Sprite`, что обеспечивает:
- Эффективную обработку коллизий
- Групповые операции над объектами
- Автоматическое управление памятью

### Модульная архитектура
Разделение на модули обеспечивает:
- Легкость сопровождения кода
- Возможность независимого тестирования
- Расширяемость функциональности

### Обработка ресурсов
- Поддержка работы как в development режиме, так и в собранном виде (PyInstaller)
- Централизованное управление путями к файлам
- Обработка ошибок загрузки ресурсов
