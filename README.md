# Alien Invasion (Инопланетное вторжение)

## Описание проекта

Классическая 2D аркадная игра "Alien Invasion", созданная на Python с использованием библиотеки Pygame. Игрок управляет космическим кораблем, защищая Землю от волн атакующих инопланетян.

### О чем эта игра?

Это реализация популярной аркадной игры в стиле "Space Invaders", где игрок:
- Управляет космическим кораблем в нижней части экрана
- Стреляет по флоту инопланетян, движущихся сверху
- Набирает очки за уничтожение врагов  
- Проходит уровни с возрастающей сложностью
- Имеет ограниченное количество жизней

## Игровая механика

### Управление:
- **← →** (стрелки влево/вправо) - движение корабля
- **Пробел** - выстрел
- **Q** - выход из игры
- **Мышь** - нажатие кнопки "Play" для начала игры

### Особенности:
- Звуковые эффекты (выстрелы, взрывы, попадания)
- Система очков и уровней
- Увеличение скорости с каждым уровнем
- Ограничение на количество пуль на экране
- Отображение статистики (счет, уровень, жизни)

## Структура проекта

### Основные модули:
- **`alien_invasion.py`** - главный класс игры и игровой цикл
- **`ship.py`** - класс корабля игрока
- **`alien.py`** - класс инопланетян
- **`bullet.py`** - класс пуль/снарядов
- **`settings.py`** - настройки игры (скорость, размеры, цвета)
- **`game_stats.py`** - статистика игры (счет, жизни, уровень)
- **`scoreboard.py`** - отображение счета и статистики
- **`button.py`** - кнопки интерфейса

### Вспомогательные модули:
- **`utils.py`** - утилитарные функции (работа с ресурсами, курсор мыши)
- **`color.py`** - константы цветов
- **`game_functions.py`** - дополнительные игровые функции

### Ресурсы:
- **`images/`** - спрайты (корабль, инопланетяне)
- **`sounds/`** - звуковые эффекты (выстрелы, взрывы)

## Установка и запуск

### Требования:
- Python 3.6+
- Pygame

### Установка зависимостей:
```bash
pip install pygame
```

### Запуск игры:
```bash
python alien_invasion.py
```

### Создание исполняемого файла:
```bash
pyinstaller --onefile --windowed --debug all --add-data "images;images" --add-data "sounds;sounds" alien_invasion.py
```
